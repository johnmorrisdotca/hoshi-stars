[English](../constellation-quiz.md)

デモの `quiz.html` は、1つの星座のまわりの星の図を、名前を書かずに見せ、その下に6つの名前を1列に並べます。1つ選ぶと、正解は緑になり、まちがいはゆれて (動きを減らす設定ではゆれません)、正しい名前を教えてくれます。**次の問題**で次へ進みます。ページを開いているあいだ、スコア、連続正解、そしてまちがえた星座を、絵とページへのリンクつきで問題の下に残します。

- **見た目**で、やさしさを変えられます。*星だけ* (星以外は何もなし、いちばんむずかしい)、*星と線* (星座の図の線も)、*ヒントつき* (線、IAUの境界線、となりの星座の名前。答えの星座の名前は書きません)。
- **レベル**は、出す星座です。*明るい12* (図の星の光をあわせるといちばん明るい12の星座)、*明るい30*、*88すべて*。まちがいの5つの名前も、同じレベルから選びます。
- **文化**で、ほかの空を出せます。*日本* (日本の名前と結び方の88星座と、日本に伝わる星のならび。カタログに星が3つ以上あり、線が2本以上ある図) と、*中国* (カタログに星が3つ以上あり、線が2本以上ある中国の空の図。二十八宿と、そのあとの星官。レベルは下の項を見てください)。名前はデータそのままです。日本の空は日本語か英語 (古いならびは読みつき、昴 (すばる))、二十八宿は繁体字で、データに英語名があれば英語、なければピンインをそえます。日本語のページでは、Wikidataに日本語のラベルがあればそれを出します (庫楼と文昌の2つは訂正してあります)。ラベルがなければ、繁体字の名前のうち日本語に標準の字形がある字 (參は参、攝は摂など) だけをその字形に直して出します。字形がそろい、字の形から答えがわからないようにするためです (婁、畢、觜、軫、張、氐は日本語でも同じ字なので、そのままです。礪と瀆も、ふつうに印刷される字形なので、そのままです。鱉は鼈、廁は厠と、どの電話でも表示される字形で出し、螣蛇は、日本でよく知られている騰蛇と書きます)。レベルはその空のもので、図はその文化の線を描き、*ヒントつき*はありません (境界線ととなりの星座が西洋の空のものなので)。アドレスには `culture` (`japanese` か `chinese`。西洋が初めの設定) が残ります。
- **中国のレベル**は順に、*明るい12*と*21すべて* (カタログに星が3つ以上ある二十八宿。残りの7宿は星がそれより少なく)、*小さな宿 (7)* (その7宿を、ふつうとは逆に出します。下を見てください)、*紫微垣 (14)*と*天市垣 (8)* (Wikidataが所属を示している星官)、そのあとの*星官 1*から*4* (24ずつ。残りの星官を明るい順に) です。どの星官もひとつのレベルにだけあり、まちがいの5つの名前も同じレベルから選びます。太微垣は該当が2つしかなく、6つの名前に足りないので、その2つ (と、宿に属する1つ) は星官のレベルに入っています。ほかの星官と名前が同じ図 (古い一覧には五諸侯が2つあります) は、どちらも正解にならないので出しません。**小さな宿** (角、氐、虚、室、壁、婁、觜。カタログにある星が1つか2つで、図にはなりません) は「丸でかこんだ星は、どの宿?」と聞きます。図の範囲はいつも同じ (図の中心から短い辺の半分の42%までが20度、およそ48度の幅) で、その宿の星の中心に合わせ、その宿の星だけを丸でかこみ、ほかの宿の星をうすく描きます (*星と線*では、その線もうすく)。6つの名前は、正解の宿と、二十八宿のうち空で近い5つです。問いも図もちがうので、*21すべて*に混ぜず、ひとつのレベルにしてあり、古いアドレスの意味は変わりません。丸には「基準星」とは書きません: 氐と觜には、データに1番の星がなく、Wikidataの番号にはたよらないからです。星官がどの垣に属するかは、Wikidataが示すもの (データの `partOf`。ダンプ `data-sources/chinese-constellations-wikidata.jsonl`、2026-11-17に読みました) です。このダンプから、これまでのデータにない垣は増えなかったので、レベルの図は同じです (太微垣は今も2つ)。日本語のページでは、Wikidataに日本語のラベルがある宿や星官は、そのラベル (虚宿、参宿など。38あり、2つの訂正 (庫楼、文昌) のほかはWikidataのままで、日本語の読み手の確認待ち) で出し、ほかは繁体字の名前を、同じ字だけ日本語の字形にして出します。アドレスの `level` は `12`、`88`、`small-mansions`、`purple-forbidden`、`heavenly-market`、`officials-1` から `officials-4` で、中国の空の古い `level=88` は今までどおり21の二十八宿です。選んだ空 (南緯40度からの紫微垣など) で図が6つ未満になるレベルは出さず、アドレスにあれば「すべて」になります。
- **空**で、見える星座だけに絞れます。**緯度** (-90から90までの整数の度で入力します。北がプラス。小数は四捨五入し、範囲の外の数は受け付けず、前の緯度のままにします) か*いまの場所*と、月 (*どの月でも*なら1年のうちのどこか) を選びます。その月の15日の21時に、星座の図の星の半分より多くが地平線から10度より高くにあれば、見える星座とします。計算はパッケージの `horizontal` で行います。北半球では南十字星は出ず、7月の夜のオリオン座も出ません。レベルはその空の中から選ばれ、6つの名前もそこから選ばれます。アドレスには `lat` (整数の度) と `month` (1から12) が残ります。以前のリンクの `hemisphere=north` と `south` も、40と-40として今までどおり開き、両方あれば `lat` が優先です。空にすると全天です。この空で図が少なすぎるレベルは、今までどおり出しません。
  **いまの場所**は、ボタンを押したときだけ端末に場所をたずね、緯度だけを整数の度に丸めて使います。位置は残しません。アドレスには書かず (丸めた緯度もです。コピーしたリンクやフレームのコードに入らないのは、今夜のページや私の空のページと同じです)、保存も送信もしません。再読み込みすると消えます。残したいときは緯度を入力してください。場所が共有されなかったときや端末がわからないときは、そう表示して、それまでの緯度のままにします。
- **自分のページに入れる**: クイズの下のパネルで、フレームのコード (`<iframe src=".../embed-quiz.html?level=88&style=lines&kid=1">`) が、幅320、480、640で出ます。埋め込みのページは、操作ボタンのないクイズです。アドレスで `style`、`level`、`kid=1`、`lat` (または古い `hemisphere`)、`month`、`lang=ja` を決め、アドレスには何も書き戻さず、問題はコードに入りません。
- まちがいの5つの名前は、答えとまちがえやすいものです。となりの星座を3つまで、次に同じ時代につくられた星座、そのあとレベルの残りから選びます。矢印キーで6つの名前のあいだを動けます (上下は1行ぶん)。1から6のキーで答えられます。
- **キッズモード** (レベルのよこのボタン) にすると、どのボタンも高さ56px以上になり、6つの名前はさらに大きくなって、言葉もやさしくなります (「これは なにざ?」「やったね! オリオン座だよ!」、かんたん・ふつう・むずかしい)。アドレスに `kid=1` が残ります。えらぶまで答えがわかるものは出ません。
- アドレスには `style` (`lines` か `annotated`。星だけが初めの設定)、`level` (`30` か `88`。明るい12が初めの設定)、問題 `q` が残ります。`q` は88の星座の並びでの番号で、1から始まります (`quiz.html?q=60&level=88`)。読み込みなおしても、リンクを人に送っても、同じ問題、同じ答え、同じまちがいの5つの名前が出ます。まちがいの名前は問題から決まるので、同じリンクを二度開いて見くらべても、答えはわかりません。アドレスに星座の名前は入りませんが、番号は調べられるので秘密ではありません。手で書いた `c=Ori` も読むので、決めた星座を出すこともできます。これはテストではなく、教室や家で遊ぶクイズです。

図は、パッケージの `chart()` を問題ごとに1回描いたもので、`centreOfConstellation` を中心に、星座の図がちょうど入る大きさにしてあります。考えているあいだは、動くものも描きなおしもありません。1から6のキーで名前を選べ、答えたあとはフォーカスが「次の問題」に、そのあとは最初の名前に移ります。スマートフォンでも使え、6つの名前は2列か3列になり、日本語のページでは名前が日本語になります。
