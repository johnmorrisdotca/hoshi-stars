[English](../one-sky-three-traditions.md)

星はだれにとっても同じですが、星をつないで描いた絵は、人によって違います。このガイドでは、見つけやすい5つの星の並びを取り上げ、3つの伝統が同じ星をどうつなぎ、どう名づけたかを紹介します。3つの伝統とは、国際天文学連合の88星座（西洋の空）、日本に伝わる星の名前、そして中国の三垣二十八宿（さんえんにじゅうはっしゅく）の空です。どの並びにも[デモ](https://johnmorrisdotca.github.io/hoshi-stars/?lang=ja)へのリンクがあります。リンクを開くと、その伝統とその星の並びが選ばれた状態でデモが開きます。授業では3つを切り替えて、同じ星の上で線が変わるのを見られます。

このガイドの内容は、すべて hoshi-stars に入っているデータ（星、名前と読み方、星座の線）にもとづいています。短いお話は、私たちの言葉で書きました。このデータの注意点は最後にまとめました。授業で使う前に、ぜひお読みください。

## 授業でのデモの使い方

- 下のリンクを開きます。その星の並びが選ばれていて、カードに名前、読み方、説明が出ます。
- **星座の文化**を、西洋・日本・中国で切り替えます。星は同じ場所のままで、線と名前だけが変わります。
- 問いかけてみましょう。それぞれの伝統は、どの星を選んだでしょうか。どの星が入っていないでしょうか。それぞれの人たちは、星に何を見たのでしょうか。

## 1. オリオン座、鼓星、參宿

| | 名前 | 読み方 | 説明 |
|---|---|---|---|
| 西洋 | オリオン座 | | 狩人の星座（Ori） |
| 日本 | 鼓星 | つづみぼし | 砂時計の形の鼓に見立てたオリオン座 |
| 中国 | 參宿（参宿） | shēn xiù（シェン・シウ） | 白虎の宿（しゅく）のひとつ「三つの星」 |

西洋では、オリオン座は三つ星のベルトをしめた狩人です。日本では、同じ星で鼓を描きます。鼓はまん中が細い小さな太鼓で、ベルトが鼓のくびれにあたります。日本では、いちばん明るい2つの星にも名前があります。赤いベテルギウスは平家星（へいけぼし）、白いリゲルは源氏星（げんじぼし）です。源平の戦いで、平家が赤い旗、源氏が白い旗を使ったことからきています。ベルトの3つの星は三つ星（みつぼし）です。中国では、この並びを「三」という意味の參（しん）と呼びます。ベルトの3つの星にちなんだ名前です。空の西側にある白虎の7つの宿のひとつです。

## 2. 北斗七星と北斗

| | 名前 | 読み方 | 説明 |
|---|---|---|---|
| 西洋 | 北斗七星（Big Dipper） | | おおぐま座の明るい7つの星 |
| 日本 | 北斗七星 | ほくとしちせい | 北のひしゃくの7つの星 |
| 中国 | 北斗 | běi dǒu（ベイ・ドウ） | 北のひしゃく |

西洋では、この7つの星は星座ではありません。おおぐま座の一部で、北斗七星は星座の中にある星の並び（アステリズム）です。ひしゃくの先の2つの星を結んだ線をのばすと、北極星が見つかります。日本では中国の名前の北斗七星をそのまま使い、七つ星（ななつぼし）や、四三の星（しそうのほし：水をくむ部分の4つと柄の3つ）とも呼びます。中国では、北極の近くにあるひしゃくです。夕方に柄がどちらを向いているかで季節がわかる、という古い言い伝えがあります。

## 3. プレアデス星団、昴、昴宿

| | 名前 | 読み方 | 説明 |
|---|---|---|---|
| 西洋 | プレアデス星団（M45） | | おうし座の星団、「七人姉妹」 |
| 日本 | 昴 | すばる | プレアデス星団。六連星（むつらぼし）とも呼びます |
| 中国 | 昴宿 | mǎo xiù（マオ・シウ） | 白虎の宿のひとつ。昔は「髦頭（ぼうとう）」とも呼ばれました |

小さくかたまった星の集まりで、多くの人の目には、6つか7つの星に見えます。西洋では「七人姉妹」と呼ばれます。おうし座にある星団で、メシエカタログの45番（M45）です。日本では昴（すばる）、または「6つの星が連なる」という意味の六連星と呼びます。中国では昴と呼びます。1でとりあげた參と同じ、白虎の7つの宿のひとつです。

## 4. 夏の大三角、織姫と彦星、織女と河鼓

| | 名前 | 読み方 | 説明 |
|---|---|---|---|
| 西洋 | 夏の大三角 | | 3つの星座にまたがる、ベガ・アルタイル・デネブ |
| 日本 | 織姫と彦星 | おりひめ、ひこぼし | 機織りのベガと、牛飼いのアルタイル |
| 中国 | 織女（织女）と河鼓 | zhī nǚ（ジー・ニュイ）、hé gǔ（ホー・グー） | ベガをふくむ「織女」と、アルタイルをふくむ「河鼓（かこ）」 |

西洋では、こと座・わし座・はくちょう座の3つの星座の明るい星を結んで、夏の夜の大きな三角形にします。日本と中国では、そのうち2つの星についてのお話があります。ベガは天帝の娘で機織りの織姫、アルタイルは牛飼いの彦星です。二人は結婚すると仕事をしなくなり、怒った天帝によって天の川をはさんで離ればなれにされました。年に一度、7月7日の夜（中国や昔の日本では旧暦の7月7日）にだけ会えます。この日の行事が、日本の七夕（たなばた）、中国の七夕（チーシー）です。中国の空では、織姫の星座は織女で、ベガとそのそばの小さな星です。アルタイルは河鼓（川の太鼓）のいちばん明るい星です。デネブはこのお話には出てきません。

## 5. さそり座と、青龍の心臓

| | 名前 | 読み方 | 説明 |
|---|---|---|---|
| 西洋 | さそり座（Scorpius） | | 赤いアンタレスを心臓に持つサソリ |
| 日本 | さそり座 | さそりざ | 星座の日本語の名前 |
| 中国 | 心宿 | xīn xiù（シン・シウ） | 青龍の宿のひとつ「心」 |

西洋ではサソリに見立て、赤いアンタレスがその心臓です。中国では、もっと大きな生きものの一部に見ます。空の東側の青龍で、その7つの宿がこのあたりに並んでいます。アンタレスは心（心臓）のまん中の星で、サソリの長いしっぽは、青龍の尾（しっぽ）です。オリオン座とさそり座は空の反対側にあるので、一方がのぼると、もう一方は沈みます。中国には、參（オリオン座のベルト）と商（心の古い名前）を使って、会うことのない二人をたとえる古い言葉があります。日本にも、このあたりの星の昔の呼び名がありますが、hoshi-stars にはまだ入っていないので、日本の空では、今の星座の名前で表示します。

## 授業で伝えてほしい3つの注意点

- **中国の星座の線は、私たちがつないだものです。** 出典からわかるのは、どの星がその名前を持つかだけで、昔の星図でどうつないでいたかはわかりません。デモの線はこのパッケージが引いたもので、昔の星図では同じ星を別の形でつないでいることがあります。
- **データにない星があります。** このパッケージにあるのは6.0等までの星です。6.0等は、暗い夜空でやっと目に見えるくらいの明るさです。中国の星座の多くにはもっと暗い星があり、また出典（Wikidata）には明るい星でもカタログ番号が書かれていないものがあるので、描いていない星があります。足りない星があるときは、カードに「データにない」と出ます（參、昴、織女、河鼓は、どれも少なくとも1つ足りません）。どちらが理由かは、いつも分かるとは限りません。
- **中国の星の名前は Wikidata から取りました。** どの星がどの名前を持つかは、だれでも編集できるデータベースの Wikidata から読んだもので、昔のカタログと一つずつは照らし合わせていません。日本の名前は、伝統的な星の名前をまとめた一つのリストから取りました。どちらも、出発点として使ってください。最終的な答えではありません。

3つの空の名前、読み方、星座の線と、それぞれの出典は、[星座の文化](sky-cultures.md)と[データとライセンス](data-and-licences.md)にあります。
